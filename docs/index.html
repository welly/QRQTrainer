Press play, listen to the whole callsign, then type what you heard. The app runs 50 of these in a row, adjusting the speed after every one.

To make it easier, this demo leaves extra space between letters (Farnsworth spacing). The app sends at true speed unless you turn Farnsworth spacing on in Settings.

Install in a minute.

QRQ Trainer is free and open source. It isn't signed with an Apple Developer ID yet, so macOS asks you to confirm the first launch.

  1. Download QRQ-Trainer.dmg, open it, and drag QRQ Trainer into Applications.
  2. Open it. When macOS says it can't verify the developer, click Done (or Cancel).
  3. Go to System Settings → Privacy & Security, scroll down and click Open Anyway next to QRQ Trainer. You only need to do this once.

Prefer Terminal? This removes the download quarantine flag:

xattr -dr com.apple.quarantine "/Applications/QRQ Trainer.app"

Questions

What do CPM and WPM mean?

CPM is characters per minute, the traditional unit for callsign trainers. WPM is words per minute using the standard "PARIS" word, so 1 WPM = 5 CPM. You can switch between them in the app.

Where do the callsigns come from?

The built-in generator makes realistic calls from about 60 ITU prefix groups, with optional /P, /M and foreign prefixes. For real, active callsigns, import the Super Check Partial MASTER.SCP file under Settings → Callsigns.

How is the score calculated?

Each callsign or group is worth its Morse length × speed ÷ 100. Each wrong character reduces that. Response time runs from the start of the sound to pressing Return, and only the time after the sound has ended costs points: 3% per second, never below half. A repeated item scores zero. Every result shows its points, the maximum available and the response time in milliseconds. Scores are only comparable between attempts with the same source and length (50 is standard).

Is this RufzXP?

No. It's an independent, open-source app inspired by the classic callsign-copying training method, and it isn't connected to the RufzXP International Toplist. You can export your results as CSV.

Does it work on Windows or Linux?

No, it's a native macOS app (macOS 14 Sonoma or later). The Morse and scoring logic is plain Swift, so other ports are possible.
